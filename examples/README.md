# 示例

## 不需要任何数据就能跑

    python examples/demo_reward_round.py

这个脚本自己造一批「真实质量与作者名气无关、但互动量被名气污染」的帖子，
跑完整四步，打印本周获奖名单。在 900 篇合成帖上的实测输出：

| | 朴素（按互动量排） | 本算法 |
| --- | --- | --- |
| 获奖者平均真质量 | +0.480 | **+0.861** |
| 获奖者平均作者名气 | +0.522 | **−0.424** |
| 两份名单重合 | — | 224 / 361 |

朴素排序选出的是已经很有名的作者；本算法选出的是真正写得好的帖子。
脚本末尾会自己断言「预测分更贴质量而不是名气」，跑不过就退出非零。
